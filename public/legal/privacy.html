Privacy Notice

This notice describes the current implementation. Provider-side logs and retention settings should be confirmed before launch; this page is not a claim that every provider setting has been audited.

1. Information you submit

The public listing suggestion form asks for a listing name, category, short description, region, optional country code, official website URL and public verification source URL. It does not ask for your name, personal phone number or private address. Suggestions remain pending for moderator review and are not displayed in the public directory unless approved.

2. Anti-abuse verification and service providers

The suggestion form uses Cloudflare Turnstile when configured to help limit automated abuse. FurFinder is hosted through Vercel and uses Supabase for the directory and moderation database. Those providers may process technical request information under their own terms and privacy notices. Review their current notices for provider-specific processing and retention details.

3. Browser storage and cookies

The current interface stores essential consent and terms acknowledgements in local browser storage. Display settings can be stored as optional preferences only when you enable the Preferences category. The current implementation does not install analytics or marketing trackers and does not intentionally set advertising cookies. Essential storage is required to remember your choices. Clearing browser storage may cause the notices to appear again.

4. Your choices

Use the Privacy settings control to save optional preferences, reject optional categories or change your choices. Essential storage cannot be disabled within the interface because it is used to remember the consent state. Analytics and marketing categories are shown for transparency but are not active integrations in the current build.

5. Public directory data

Published directory entries contain public organization or event information and official source links. They are not intended to contain private personal data. Regional ratios count published directory entries; they are not personal profiles or population estimates.

6. Retention and security

Suggestions may be retained as pending, published, rejected or archived records for directory operations and moderation history. Access is controlled by database permissions and moderation authorization. No online service can guarantee absolute security; do not submit confidential information.

7. Children and age-related rules

FurFinder is designed for public discovery and does not provide private messaging or private meetup matching. External communities and events may have different age restrictions. Follow their published rules and obtain parent or guardian involvement where required. FurFinder does not help bypass age restrictions.

8. Requests and updates

For correction or removal requests about a public listing, contact the project through its repository issue tracker. Do not post personal or sensitive information in a public issue. This notice will be updated when the service's data practices change.
